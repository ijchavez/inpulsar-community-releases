# Inpulsar Community Edition

**Official Windows releases by Neon Pulsar Labs.**

Inpulsar Community Edition is a free input overlay application for Windows, designed to visualize keyboard and controller inputs during gameplay, recording, streaming, and content creation.

## Downloads

Official installers and release notes are available in the [Releases](https://github.com/ijchavez/inpulsar-community-releases/releases) section.

**Platform:** Windows x64  
**Distribution:** NSIS installer (per-user)  
**Edition:** Community — Freeware

## Installation

1. Download the latest official Windows installer from Releases.
2. Verify its SHA-256 checksum using the accompanying `SHA256SUMS.txt`.
3. Run the installer and follow the installation instructions.

The installer is currently unsigned. Windows SmartScreen may display a security warning. Verify the official download source and checksum before proceeding.
